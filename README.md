Todo / TaskList

Небольшой todo-лист, который я делал, чтобы разобраться с React и тем,
как в нём работать с состоянием и списками.

Это не коммерческий проект и не копия туториала, а штука, которую я постепенно
допиливал сам, переписывая логику с обычного JavaScript на React.

Проект задеплоен на GitHub Pages:  
https://delovo1.github.io/tasklist/

Что здесь есть:
— добавление задач  
— удаление задач  
— отметка выполненных  
— простые анимации при удалении элементов  

Основной упор был не на дизайн, а на логику:
— работа с массивами в useState  
— корректное обновление состояния через prev  
— понимание, как React работает с key и id  
— почему transition не работает при удалении элементов и как это обходить  

Стек:
React  
JavaScript  
CSS  

Как запустить локально:
git clone https://github.com/delovo1/tasklist.git  
cd tasklist  
npm install  
npm start  

Планы:
Хочу добавить сортировку задач и доработать анимации.
Возможно позже подключу сохранение данных или API.

Проект сделан в процессе обучения.
